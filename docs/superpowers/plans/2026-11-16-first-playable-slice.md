# First Playable Slice (MEM-87) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Walk a 3D building site built from a real GitHub Projects board, open a pallet's card, and move it to another column for real through a confirmation, with an action log, in English and French, plus a demo site that needs no account.

**Architecture:** One package. `src/shared` holds pure logic (config, site model, gesture preparation). `src/server` is a Hono app, the only code that talks to GitHub (GraphQL) and Postgres (Drizzle), served inside Vite in development by `@hono/vite-dev-server`. `src/client` is the React Three Fiber game and its React UI, calling the server through Hono's typed client.

**Tech Stack:** React 19.3, React Three Fiber 9.8, Three.js 0.187, drei 10.7, @react-three/rapier 2.2, ecctrl 2.0, zustand 5, @react-three/postprocessing 3.2, Hono 4.13, @hono/vite-dev-server 0.26, @hono/zod-validator 0.9, zod 4, @octokit/graphql 9, Postgres 18 (Docker), drizzle-orm 0.45, drizzle-kit 0.31, postgres 4.1, i18next 27, react-i18next 18, i18next-browser-languagedetector 8, Vite 8, TypeScript, Vitest 5, Playwright 1.65, oxlint, lefthook 2, Blender 5.3 (headless), @gltf-transform/cli 4.5.

**Spec:** `docs/superpowers/specs/2026-11-16-project-quest-design.md`

## Global Constraints

- Test board only: `memolabs-dev` project 6, repository `memolabs-dev/rescue-atlas-lab`. Never `dataforgoodfr`.
- The lab board's status options are, in order: `Backlog`, `Ready`, `In progress`, `In review`, `Done`. Its iteration field is named `Sprint`, its size field `Size`. These names live in `quest.config.json`, never in code.
- Every GitHub write is prepared, shown in full, confirmed by a click, re-checked for staleness, then applied and logged.
- The browser never holds a GitHub token. The server gets it from `gh auth token` (or `GITHUB_TOKEN` if set).
- English and French for every user-facing string, from this slice on.
- Test data is invented and its titles contain `FICTIF`.
- Assets committed to the repo are CC0 or generated by our Blender scripts.
- Interface motion 100 to 300 ms, ease `cubic-bezier(0.23, 1, 0.32, 1)`; `prefers-reduced-motion` turns off camera moves and particles but keeps colour and focus feedback.
- Git regime A: small conventional commits on `main`, referencing `MEM-87`; lint, types and tests pass locally before each push.

## Review Focus

1. **A board item whose status option is not in the config** (option renamed on GitHub): the server refuses to start the site with a message naming the unknown option, instead of putting pallets in a phantom zone. Test in Task 1.
2. **The item changed on GitHub between the confirmation and the click** (someone else moved it): apply refuses, returns the new state, and the UI asks again. Test in Task 3.
3. **`gh` not logged in, or no access to the board**: the site shows a plain message with the command to run and a button to open the demo site, not a blank canvas. Test in Task 5.
4. **Worst-case titles** (200 characters, an unbreakable URL, Arabic, emoji): the card and the 3D label never overflow. Test in Task 9.
5. **A board with no epics, or issues with no parent**: the site still renders, with those pallets in a "Hors chantier / Unassigned" building. Test in Task 1.
